# Manuscript

`Scratch-NeurIps.pdf` is the NeurIPS 2026 camera-ready paper. The LaTeX source
and figure files are not distributed with this repository.

## Outcome definitions

The camera-ready primary outcome is the unit-test pass rate reviewed by an
independent LLM auditor (MiMo-V2.6-Pro; see
`docs/independent_audit_protocol.md`). Appendix F repeats the main analyses on
raw unit-test outcomes and on the reviewed (submitted) version's outcome, in
which an `o4-mini` audit covered only the earlier construction frame. Every
number in the manuscript comes from `results/camera_ready/<outcome>/`, where
`<outcome>` is `independent_audit` (primary), `reviewed_outcome`, or
`harness_outcome`. `scripts/camera_ready/paper_numbers.py` prints them.

## Figures

The six figures in the paper are generated by
`scripts/generate_stage_d_paper_figures.py`, which writes them to `paper/` (the
images are not tracked) and by default reads the primary-outcome scored files
(`data/stage_d/scored_independent_audit`) and result set
(`results/camera_ready/independent_audit`):

```bash
python scripts/generate_stage_d_paper_figures.py
```

`CK_SCORED_DIR` and `CK_RESULTS_DIR` select another outcome. The extension
tables and figure use raw harness outcomes on both sides, because the extension
runs saved no code to audit. Display bin $b$ contains composite values in
$[b-0.5,b+0.5)$, so exact half-point boundaries enter the higher bin; threshold
inference uses the continuous, unbinned composite. In `pass_vs_output_cc.csv`,
bin 40 is top-coded as 40 or greater. Under the primary outcome,
`reverse_threshold_zero_pass_cells.csv` contains 14,247 failed complete cases
(outcome 0) and excludes 969 failed generations without computable output CC.
